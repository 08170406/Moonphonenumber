# Moonphonenumber
9月moonbit比赛

MoonBit phone number library for China (CN), France (FR), the United Kingdom
(GB), and Singapore (SG). This initial scaffold defines the public API; regional
parsing, formatting, validation, and as-you-type behavior follow in later tasks.

The metadata subset is based on Google libphonenumber v9.0.39; see `NOTICE`.
